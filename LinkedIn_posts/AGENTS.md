# Instrução para assistentes que editarem este diretório

**Antes de escrever qualquer publicação de LinkedIn**, leia, nesta ordem, `README.md`, `SKILL.md`, `PUBLICACOES.md`, `IDEIAS_E_CASES.md` e `GUIA_INTERACOES_E_EVOLUCAO.md` (neste mesmo diretório). O calendário é: **TERÇA — networking com dores reais de SFMC**; **QUINTA — soluções/cases existentes no GitHub/portfólio**.

Verifique temas e projetos já `PUBLICADO` ou `RASCUNHO`; diferencie-os e evite repetição de tema/ângulo. Posts são escritos em português brasileiro natural. Para quinta, releia o GitHub atual antes de citar projeto. Não invente cases, resultados, métricas ou experiências. Preserve confidencialidade de clientes e não publique no LinkedIn automaticamente.

Se tiver permissão autorizada para atualizar o GitHub, registre novas sugestões como `RASCUNHO` em `PUBLICACOES.md`, preservando histórico. Só altere para `PUBLICADO` após confirmação expressa do usuário. **Não altere o código do portfólio ao gerenciar esta skill.**

Quando o autor enviar prints de posts, comentários, métricas ou DMs, seguir `GUIA_INTERACOES_E_EVOLUCAO.md`: ler só informações visíveis, escrever respostas curtas e personalizadas a comentários ainda pendentes, tirar aprendizados para conteúdos futuros e orientar networking com empresários de Portugal. Não guardar dados pessoais, comentários nominais ou mensagens privadas neste repositório público. Não alegar monitoramento contínuo.

Para qualquer outra IA, usar o comando universal do README. A leitura automática deste arquivo depende do agente; o README continua sendo a entrada canônica.
